# 📊 HR Employee Attrition Analysis

### هل نقدر نتوقع مين هيمشي من الشركة قبل ما يمشي؟

مشروع تحليل بيانات لموظفين شركة، بنحاول نفهم ليه الموظفين بيسيبوا الشغل، وإيه العوامل اللي بتخلي الموظف يقرر يمشي.

---

## 🎯 هدف المشروع
- تحليل أسباب تسرب الموظفين (Attrition)
- معرفة العلاقة بين المرتب، والـ OverTime، والرضا الوظيفي، وبين ترك الشغل
- تقديم توصيات للشركة عشان تحافظ على الموظفين الكويسين

## 🛠️ الأدوات المستخدمة
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📁 الملفات
- `HR_recovered.ipynb` : الملف الرئيسي فيه كل التحليل والرسومات
- `HR_Cleaned.csv` : ملف الداتا الأصلي

## 📊 أهم النتائج اللي وصلنالها
1. الموظفين اللي بيعملوا **OverTime** كتير، نسبة تركهم للشغل أعلى بكتير.
2. **المرتب القليل** و **قلة الترقيات** من أكبر أسباب المشي.
3. الموظفين اللي عندهم **رضا وظيفي منخفض** و **توازن ضعيف بين الشغل والحياة** بيمشوا أسرع.
4. الموظفين الجدد (أقل من سنتين في الشركة) هما الأكثر عرضة للمشي.
5. القسم والمسمى الوظيفي بيفرقوا، مش كل الأقسام زي بعض.

## 💡 التوصيات
- تقليل الـ OverTime أو تعويضه بشكل عادل
- مراجعة المرتبات للموظفين اللي بقالهم فترة من غير ترقية
- الاهتمام بالموظفين الجدد في أول سنتين
- تحسين بيئة العمل والرضا الوظيفي
